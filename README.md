# CS 280A Computational Photography Showcase

A visual archive of six projects completed for **UC Berkeley CS 280A: Introduction to Computer Vision and Computational Photography (Fall 2024)**.

[View the live showcase](https://jjjasperl.github.io/CS280A-Project-Showcase/) · [Course website](https://cal-cs180.github.io/fa24/)

![Face morphing preview](project3/output/jasper_tri.png)

## Projects

| Project | Topics | Write-up |
| --- | --- | --- |
| 1. Colorizing the Prokudin-Gorskii Collection | Image pyramids, channel alignment, normalized cross-correlation | [View project](https://jjjasperl.github.io/CS280A-Project-Showcase/project1/) |
| 2. Fun with Filters and Frequencies | Convolution, finite differences, sharpening, hybrid images, multiresolution blending | [View project](https://jjjasperl.github.io/CS280A-Project-Showcase/project2/) |
| 3. Face Morphing | Correspondences, Delaunay triangulation, affine warps, population means, caricatures | [View project](https://jjjasperl.github.io/CS280A-Project-Showcase/project3/) |
| 4. Image Warping and Mosaicing | Homographies, rectification, panorama stitching, Harris corners, ANMS, feature matching | [View project](https://jjjasperl.github.io/CS280A-Project-Showcase/project4/) |
| 5. Fun with Diffusion Models | Sampling, denoising, image-to-image translation, visual anagrams, UNet training | [View project](https://jjjasperl.github.io/CS280A-Project-Showcase/project5/) |
| 6. NeRF for Varying Geometry | Person dataset preparation, neural rendering, training and rendering debugging | [View final project](https://lisaqhou4.github.io/6/index.html) |

## Final project collaboration

Project 6 was completed collaboratively. My repository contributions included a person-data loader and fixes across training, Colab execution, and rendering. The shared implementation and contribution history are available in [lisaqhou4/nerf-vg](https://github.com/lisaqhou4/nerf-vg) and [merged PR #1](https://github.com/lisaqhou4/nerf-vg/pull/1).

## Repository scope

This repository contains the public-facing HTML write-ups and result media. Course implementation source is retained separately in a private archive to respect course-material policies.
